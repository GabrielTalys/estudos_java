# Java Virado no Jiraya

Repositório criado para acompanhar meu progresso no curso **Maratona Java Virado no Jiraya**, do [DevDojo](https://www.youtube.com/@DevDojo). Aqui registro cada aula concluída e o código que desenvolvi durante os estudos.

## Progresso

<!-- Modelo: - [Aula 03 - Tema](maratona-java/src/academy/devdojo/maratonajava/introducao/aula03): resumo curto do que aprendi -->

- [Aula 01 - Olá, Mundo](maratona-java/src/academy/devdojo/maratonajava/introducao/aula01): estrutura de uma classe, método main e System.out.println
- [Aula 02 - Tipos primitivos](maratona-java/src/academy/devdojo/maratonajava/introducao/aula02)
  - TiposPrimitivos: variável do tipo int e concatenação de texto
  - DeclaracaoeTamanhoEmMemoria: declaração dos 8 tipos primitivos e char com código Unicode
  - Strings: declaração de variável do tipo String e concatenação com texto
  - ExTiposPrimitivos: exercício com variáveis String e float e concatenação para montar uma frase
- [Aula 03 - Operadores](maratona-java/src/academy/devdojo/maratonajava/introducao/aula03Operadores)
  - Aritmeticos: comentário com os operadores aritméticos e divisão entre int e double guardada em double
  - Relacionais: resto da divisão com %, comentário com os operadores relacionais e comparações com >, < e == guardadas em variáveis boolean
  - LogicosAnd: comentário com os operadores lógicos e duas condições com && guardadas em variáveis boolean
  - LogicosOR: condição com || entre dois saldos e um preço guardada em variável boolean
  - Atribuicao: operadores de atribuição (=, +=, -=, *=, /=, %=) em variáveis int e double e incremento/decremento com ++ e --
